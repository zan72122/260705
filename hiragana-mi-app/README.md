# ほしのかわ 「み」 ✨

**遊ぶだけで ひらがな「み」の書き順が身につく、4歳児のための魔法のインクあそび。**

夜空の世界を指でなぞると、光るインクが世界に描かれます。
光の精霊が誘ってくれる「ひかるところ」から正しい書き順でなぞれたとき、
インクは **光の川** になり、光る魚たちが群れて泳ぎ、花火があがり、
「み」のつくことば(みかん🍊・みつばち🐝・みず💧…)がお祝いに登場します。

## あそびかた

1. `index.html` を iPhone / iPad の Safari で開く(縦でも横でもOK)
2. 光る星をタッチしてスタート(ここで音が有効になります)
3. あとは自由!どこを触っても星屑が舞い、魚が指を追いかけてきます
4. 光の精霊がぴょんぴょん跳ねている「ひかるところ」から線をなぞると…✨

- 「み」は **2画** 。1画ずつ完成するたびに線が光の川として夜空に定着します
- 2画そろうと大群泳+花火+ことばのお祝い
- 上手になるほど自分のインクが進化します(青い光 → 水色 → 虹色 → 星入り → 彗星)
- 進化はブラウザに保存され、次に開いても続きから

### だいじな設計:「罰ゼロ」

勉強嫌いの子のためのアプリなので、**失敗という概念がありません**。

- 始点以外を触っても「エラー」ではなく、ただの楽しい自由おえかき
- 逆走・脱線しても否定音は鳴らず、静かに自由描きに戻るだけ
- 途中で指を離したインクは「星になって夜空へ昇る」演出で消える
- 正しくなぞれた時だけ、特別に豪華なことが起きる(=正解は子どもが自分で発見する)

## iPhone / iPad へ渡すには

単一HTMLファイル・依存ゼロ・オフライン動作なので、どれでも:

- AirDrop / メール / メッセージで `index.html` を送って「Safariで開く」
- iCloud Drive や「ファイル」アプリに置いて開く
- 任意の静的ホスティングに置いてURLを開く → 共有メニューから **「ホーム画面に追加」** すると全画面のアプリとして起動します(推奨)

## 技術メモ

- 依存ゼロの単一 `index.html`(全JS/CSSインライン、外部画像なし、全てCanvas描画)
- Pointer Events + `touch-action:none`(iOS Safariのスクロール/ズーム完全抑止、セーフエリア対応)
- 2キャンバス構成: 背景・川・マスコット層+`destination-out` フェードの残像パーティクル層
- 音は全て WebAudio でコード合成(キラキラ音・水音・ファンファーレ・アンビエント)。
  なぞりの進捗に合わせて音程が上がる追従音が、それ自体書き順の誘導装置になっています
- 音声ガイドは `speechSynthesis`(ja-JP)。音声が使えない環境でも遊びが成立する冗長設計
- 字形は 1000×1000 正規化空間の Catmull-Rom 制御点 → 等間隔ポリライン。
  なぞり判定は順序付きチェックポイント方式(先読みあり・進捗率で完了判定)
- 進捗は `localStorage`(キー `hoshinokawa.v1`)。リセットは左下の ☆ を3秒長押し

### デバッグ

- `index.html?d` … 字形ガイド・許容帯・チェックポイント・状態表示
- `index.html?test` … 演出短縮+音声オフ(E2Eテスト用)

## テスト

```bash
cd test
npm install
node e2e.spec.mjs
```

Playwright(Chromium)でタッチイベントを実機同等に発行し、以下を自動検証します:

- 正しい書き順でなぞる → 画ごとの完了 → お祝い演出 → localStorage保存・インク進化
- 始点以外・逆走・途中離し → 進行せず、エラーにもならない(罰ゼロ設計の検証)
- 画面回転(縦→横)後も川が画面内に再投影され、続きをなぞれる
- 負荷中の平均フレーム時間
- 縦 / 横 / iPad の各スクリーンショットを `test/screenshots/` に出力

この開発環境ではプリインストールChromiumを使うため
`CHROMIUM_PATH=/opt/pw-browsers/chromium`(デフォルト設定済み)で実行されます。
